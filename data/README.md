# data/

Nơi lưu **toàn bộ dữ liệu của web** khi chạy với XAMPP:

- `state.json` – hội viên, phiên chơi, đơn hàng, sản phẩm, game, banner, cấu hình… (tự tạo ở lần chạy đầu tiên)
- `uploads/` – ảnh sản phẩm / game / banner đã tải lên

Hãy **commit cả thư mục này lên Git** để người khác `git pull` về là có đúng dữ liệu đó.
Nếu hai người cùng sửa `state.json` ở hai nhánh thì sẽ có xung đột Git — chọn một bản rồi tiếp tục.
